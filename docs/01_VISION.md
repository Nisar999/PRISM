# Vision

PRISM OS is not a chatbot.

PRISM OS is not a RAG wrapper.

PRISM OS is an AI Operating System.

---

# Mission

Create an AI that:

- remembers permanently
- reasons transparently
- heals itself
- evolves with the user

---

# Inspiration

PRISM OS draws inspiration from:

- Odysseus
- Claude Code
- Cloud Code
- NotebookLM
- Obsidian
- Iron Man JARVIS

---

# Principles

## 1.

Memory First.

Every interaction becomes experience.

---

## 2.

Open Source First.

No vendor lock-in.

No mandatory subscriptions.

---

## 3.

Local First.

Users own:

- memories

- models

- files

- graphs

- conversations

---

## 4.

Visual Cognition.

Users should SEE:

- memories

- thoughts

- failures

- healing

- evolution

---

## 5.

Explainability.

Every answer should answer:

Why?

How?

From where?

---

# Final Goal

Create

an AI

that grows

alongside

its user.

Not for a session.

For years.
